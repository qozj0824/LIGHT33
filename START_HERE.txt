NØXIS v38.0 빠른 실행
======================

1. 이 폴더에서 install.bat 실행
   또는 PowerShell:
   python -m pip install -r requirements.txt

2. run.bat 실행
   또는 PowerShell:
   python -m uvicorn app:app --host 127.0.0.1 --port 8010

3. 브라우저에서 열기
   http://127.0.0.1:8010

처음 1회
--------
장비 프로필 관리 → 같은 망원경/카메라/필터/Gain 조합의 기준 천체사진 등록 →
기준 영상 선택 → 촬영시각 자동 확인 → (선택) 기준 천체 가져오기 → 프로필 생성
   * Stellarium 날짜가 달라도 생성은 중단되지 않습니다. 필요하면 화면 버튼으로 기준 촬영시각에 맞출 수 있습니다.

매 관측일
----------
현재 전천 영상 입력 → Stellarium에서 오늘 촬영할 천체 선택 → 저장된 장비 프로필 선택 → 분석

주의
----
- `pip -m install`이 아니라 `python -m pip install`입니다.
- 정량 분석은 RAW/FITS를 권장합니다.
- Csys 정밀 보정을 위해 장비 등록 때 같은 시각·장소의 기준 전천 영상을 함께 등록하면 좋습니다.
- 결과는 작품설명서의 모델에 따른 관측 계획 시작값이며 모든 실제 조건에서 절대적인 최적값을 보장하지 않습니다.


v38.0 천체 구조 + 스택 효율
--------------------
고정 심우주 대상에 RA/Dec가 있으면 분석 중 공개 DSS2 참조 영상을 자동 조회해 상대 밝기 구역을 계산합니다.
조회 실패 시 분석 전체가 실패하지 않고 기존 평균 표면밝기 방식으로 자동 대체됩니다.
결과 화면의 '천체 밝기 구역'과 '스택 효율 곡선'을 확인할 수 있습니다. 총 적분시간은 목표 SNR을 강제 달성하도록 역산하지 않고 기본 12시간 계획범위 안에서 밝기 구역별 정보 한계효용을 사용합니다.
Render가 재시작되어 서버 장비 프로필이 사라져도 같은 브라우저의 compact core snapshot으로 자동 복구하며, 프로필 관리에서 JSON 내보내기/가져오기를 사용할 수 있습니다.
