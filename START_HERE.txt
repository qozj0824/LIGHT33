LIGHTT v34.2 빠른 실행
======================

1. 이 폴더에서 install.bat 실행
   또는 PowerShell:
   python -m pip install -r requirements.txt

2. run.bat 실행
   또는 PowerShell:
   python -m uvicorn app:app --host 127.0.0.1 --port 8010

3. 브라우저에서 열기
   http://127.0.0.1:8010

처음 1회
--------
장비 프로필 관리 → 같은 망원경/카메라/필터/Gain 조합의 기준 천체사진 등록 →
기준 영상 선택 → 촬영시각 자동 확인 → (선택) 기준 천체 가져오기 → 프로필 생성
   * Stellarium 날짜가 달라도 생성은 중단되지 않습니다. 필요하면 화면 버튼으로 기준 촬영시각에 맞출 수 있습니다.

매 관측일
----------
현재 전천 영상 입력 → Stellarium에서 오늘 촬영할 천체 선택 → 저장된 장비 프로필 선택 → 분석

주의
----
- `pip -m install`이 아니라 `python -m pip install`입니다.
- 정량 분석은 RAW/FITS를 권장합니다.
- Csys 정밀 보정을 위해 장비 등록 때 같은 시각·장소의 기준 전천 영상을 함께 등록하면 좋습니다.
- 결과는 작품설명서의 모델에 따른 관측 계획 시작값이며 모든 실제 조건에서 절대적인 최적값을 보장하지 않습니다.
