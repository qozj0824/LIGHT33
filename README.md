# NØXIS v35.1

**방향별 하늘 배경과 저장된 장비 프로필을 이용한 천체 촬영 계획 프로그램**

NØXIS v35.1는 작품설명서의 전천 영상 분석, 방향별 배경광 추출, 장비 특성 반영, 대기소광, SNR·포화·스택 계산 원리를 하나의 로컬 웹 프로그램으로 연결한 배포본입니다.

## v34.2 핵심 수정

- 과거 망원경 기준 영상과 현재 Stellarium 시각이 크게 달라도 장비 프로필 생성을 중단하지 않습니다.
- FITS/RAW 촬영시각을 자동 확인하고, RA/Dec+관측 위치가 있으면 기준 촬영시각의 Alt/Az를 자동 재계산합니다.
- 재계산 불가 시 시간 의존 보정만 비활성화하고 Gain/read noise/PSF/배경/포화 진단 등 장비 정보는 저장합니다.
- FITS WCS 중심 좌표와 관측지 헤더가 있으면 기준 방향 복원에 우선 활용합니다.
- UI에서 Stellarium을 기준 영상 촬영시각으로 이동하거나 현재 시각으로 복귀할 수 있습니다.

## v34.2의 사용 구조

망원경 기준 영상은 매 관측마다 다시 올리지 않습니다. `장비 프로필`을 처음 만들 때 한 번 분석하고 원본 기준 영상과 측정 결과를 로컬에 저장합니다. 오늘 촬영하려는 대상과 같은 천체일 필요는 없으며, 같은 망원경·카메라·필터·Gain/binning 조합으로 찍은 과거 기준 영상도 사용할 수 있습니다. 이후 실제 관측에서는 다음 세 정보만 기본적으로 사용합니다.

1. 현재 시점의 전천 RAW/FITS 영상
2. Stellarium에서 선택한 관측 대상
3. 저장된 장비 프로필

장비 프로필은 **망원경 + 카메라 + 필터 + 카메라 Gain/ISO + binning** 조합 단위로 구분하는 것을 권장합니다. 장비 설정이 바뀌면 별도 프로필을 생성하십시오.

## 장비 프로필에 저장되는 정보

- 기준 망원경 영상과 노출시간
- 변환 Gain(e-/ADU), read noise, dark current
- 센서 clipping ADU
- 기준 영상의 배경률, PSF/FWHM, 대표 peak rate(과거 시야 포화 진단용)
- 기준 천체 정보와 가능한 경우 기기영점
- 선택적으로 동일 조건의 전천 기준 영상을 이용한 Csys 장비 변환계수
- 보정 프레임 적용 상태와 신뢰도 진단

망원경 기준 영상은 반드시 그날 촬영하려는 천체일 필요가 없습니다. 다만 **미래 대상의 절대 신호와 필요한 촬영 장수까지 계산하려면 기준 영상에서 기기영점을 얻을 수 있어야 하므로, Stellarium에서 밝기 정보가 확인되는 기준 천체를 사용하면 유리합니다.** 기준 영상에 우연히 포함된 가장 밝은 별의 포화시간은 오늘 시야의 강제 상한으로 재사용하지 않고 과거 시야 진단값으로만 보존합니다. 확산천체 기준 영상으로 만든 영점은 자동 ROI와 통합등급에 의존하므로 점광원 표준에 비해 신뢰도가 낮게 표시됩니다.

## Csys 보정

작품설명서의 원리대로 전천 영상 ADU를 망원경 ADU로 직접 동일시하지 않습니다. 동일하거나 유사한 시각·장소에서 촬영한 기준 전천 영상이 장비 프로필 생성 때 함께 입력되면,

`Csys = 기준 망원경 배경률 / 같은 방향의 기준 전천 배경률`

을 저장합니다. 이후 현재 전천 영상의 목표 방향 배경률에 Csys를 적용합니다.

기준 전천 영상이 없거나 현재 전천 카메라/ISO·Gain/크롭/Flat 상태가 기준과 맞지 않으면 Csys를 강제로 사용하지 않고 상대배경 근사로 낮은 신뢰도의 계획값을 제공합니다.

## 설치

Python 3.12 권장. 프로그램 폴더의 PowerShell에서:

```powershell
python -m pip install -r requirements.txt
```

중요: `pip -m install`이 아니라 **`python -m pip install`** 입니다.

Windows에서는 `install.bat`을 실행해도 됩니다.

## 실행

```powershell
python -m uvicorn app:app --host 127.0.0.1 --port 8010
```

또는 `run.bat` 실행 후 브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:8010
```

## Stellarium 설정

Stellarium Remote Control 플러그인을 활성화하고 기본 주소 `http://127.0.0.1:8090`을 사용합니다. Render 같은 HTTPS 배포본에서는 브라우저가 로컬 Stellarium에 직접 연결하므로 Remote Control의 CORS 허용 Origin에 배포 주소를 등록해야 합니다. 관측하려는 천체를 선택한 뒤 NØXIS에서 `선택 천체 가져오기`를 누릅니다.

고도는 -90°~90°의 천문 좌표로 수용하되, 고도 0° 미만은 `지평선 아래`, 사용자가 지정한 최저 분석 고도 미만은 `저고도 분석 제외`로 처리합니다. 전천 영상과 Stellarium의 기준 시각을 모두 확인할 수 있으면 30분 초과 불일치를 차단하여 다른 시점의 Alt/Az로 잘못된 방향 셀을 조회하지 않도록 합니다.

## 전천 영상 분석

- RAW/FITS 권장
- 컬러 영상은 G 채널 중심 분석
- DAOStarFinder 사용 가능 시 PSF 기반 별 검출
- 원형 별 마스크와 sigma clipping
- 저고도·차폐·자료부족 셀 제외
- 방향별 median ADU 및 변동성 계산
- 극좌표 하늘 배경지도, 직사각형 지도, 상대배경 지도, 신뢰도 지도 생성
- Bias/Dark/Flat 선택 적용

JPG/PNG/TIFF는 미리보기·진단에 사용할 수 있으나 카메라 내부 비선형 처리 가능성 때문에 정량 신뢰도가 낮아집니다.

## 계산 결과

- 권장 단일 노출
- 예상 한 장 SNR
- 목표 SNR 달성에 필요한 촬영 장수
- 총 적분시간
- 배경/포화/추적 제한
- 방향별 하늘 배경
- 결과 신뢰도와 제한 사유

목표 SNR은 단일 노출을 무조건 늘리는 값으로 사용하지 않습니다. 단일 노출은 read-noise 효율과 포화·배경·추적 상한을 고려해 정하고, 목표 SNR은 주로 촬영 장수와 총 적분시간에 반영합니다.

## 과학적 범위

이 프로그램의 권장 노출은 입력 영상과 장비 정보에 기반한 **관측 계획 시작값**입니다. 한 장의 전천 영상에는 구름, 달빛, 대기광, 은하수, 습도·에어로졸 등의 영향도 포함될 수 있으며, 실제 결과에는 추적 오차·seeing·초점·필터 대역·후처리 등이 추가로 영향을 줍니다.

세부 내용은 `THEORY_AND_METHOD.md`, `REPORT_ALIGNMENT.md`, `KNOWN_LIMITATIONS.md`, `VALIDATION_REPORT.md`를 참고하십시오.


## v34.2의 추가 안전장치

- 장비 등록 중 중복 제출 방지
- 전천 미리보기 요청 경쟁 상태 방지(새 파일 선택 시 이전 요청 취소)
- 분석 중 입력·Stellarium·프로필 변경 잠금
- 기준 사진의 가장 밝은 별을 미래 관측의 강제 포화 상한으로 재사용하지 않음
- 협대역/다중대역 필터에서 Stellarium V등급 기반 절대 신호를 정밀값으로 오인하지 않도록 planning-only로 강등
- 태양은 본 심우주 촬영 노출 모델의 적용 대상에서 제외
