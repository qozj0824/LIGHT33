장비 프로필 등록

망원경·카메라·필터·Gain 조합별로 한 번 보정합니다. 웹 배포판은 계산된 장비 프로필 JSON만 현재 브라우저에 저장하며, 업로드한 원본 영상은 분석 후 서버의 임시 저장공간에서 제거됩니다.

필수동일 장비 조합으로 촬영한 단일 RAW/FITS 기준 영상. 오늘 촬영하려는 천체와 같을 필요는 없습니다.
권장기준 망원경 영상과 같은 시각·장소의 전천 영상. 있으면 보고서의 Csys 장비 변환계수를 직접 보정합니다.
기준 천체선택 사항입니다. Stellarium에서 기준 영상의 주대상을 가져오면 RA/Dec와 V등급을 이용합니다. 촬영시각이 다르면 프로그램이 기준 영상 시각의 고도·방위각을 자동 재계산합니다.
기준 영상 촬영시각 파일을 선택하면 촬영시각과 메타데이터를 자동 확인합니다.
촬영시각이 달라도 장비 프로필 생성 자체는 중단하지 않습니다.

기준 천체 정보 선택

기준 영상의 주대상을 알면 Stellarium에서 선택해 가져오세요. 웹사이트가 사용자의 PC에 실행 중인 Stellarium에 직접 연결하므로 Remote Control 플러그인에서 CORS를 켜야 합니다. 현재 시각이 기준 영상과 달라도 RA/Dec를 이용해 촬영 당시 Alt/Az를 자동 계산합니다.
